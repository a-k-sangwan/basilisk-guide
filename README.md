# Learning Basilisk

A guide to using the [Basilisk](http://basilisk.fr) flow solver and to the mathematics behind it, by Anil Kumar (IIT Bombay).

The guide is published on the Basilisk wiki at <https://basilisk.fr/sandbox/aksangwan/basilisk_guide/README>. This repository holds the same pages and hosts the figures that the wiki pages link to.

## Contents

- `basilisk_guide/`: the wiki pages in pandoc Markdown (`README` is the contents page, one file per chapter, `references`).
- `basilisk_guide/figures/`: the 29 figures as PNG.
- `basilisk_guide/examples/`: the four example programs from chapter 5 (lid-driven cavity, vortex street, rising bubble, dam break).
- `convert.py`: the script that builds the pages and figures from the LaTeX source of the guide.
